# 播放头 · 边缘滚修复与统一拖拽轮

> 状态：✅ 已闭合。harness 424/427（仅剩基线 3 条口径冲突 AO / AQ.B×2）；core vitest 50/50；tsc 退出码 0；用户真机目测通过（手感完美）。
> 上游：播放头精修轮（热区扩尺子 + 边缘自动滚）—— 用户实测判定「需大改」，故有本轮。
> 本轮含两段：① 边缘自动滚失效修复（内核 bug）② 去留白 + 统一拖拽 + 实时读数。

## 一、本轮做了什么

### ① 边缘自动滚失效修复（内核 bug）

**现象**：拖播放头到视口边缘（EDGE_ZONE_PX=48 触发带内），视口不再自动滚。

**根因**：`startAutoPanLoop`（src/ui/timeline/useTimelineViewport.ts）首帧自停 ——
- 起手 `lastTs = performance.now()`（在 pointermove 同步阶段取值）
- rAF 回调的 `now`（本帧起点时间戳）可能早于该值 → `dt < 0`
- `Math.max(0, dt)` 夹成 0 → 位移 0
- 位移后 `viewStartMs === before` 成立 → 被误判为「已顶到内容边界」→ 自停
- 每次 pointermove 重演 → 循环每帧只活一帧 → 完全不生效

同一函数被滚动条边缘自动滚共用 → 那条也一并失效（用户未报，同源）。

**修法**：自停条件加 dt 守卫 —— 仅当 `safeDt > 0 && viewStartMs === before` 才停（`safeDt` 复用函数内已算出的 `Math.max(0, dt)`）。

**改动**：`src/ui/timeline/useTimelineViewport.ts` 1 处（仅 `startAutoPanLoop`；`startWheelLerp` 是另一函数，未动）。

### ② 去留白 + 统一拖拽 + 实时读数

**三条需求**（用户拍板）：
1. 去留白像素（`PLAYHEAD_EDGE_PADDING_PX = 12`）—— 与「时间 0 / 歌曲末尾」冲突，播放头到不了端点。
2. 统一拖拽 —— 删掉 TimeRuler 擦洗手势，让 PlayheadLayer 播放头拖动热区覆盖整条刻度尺（「按尺子任意处 = 抓播放头」）。
3. 实时读数 —— 推翻精修轮「拖动中不写 store」，要求拖动期间底部时间读数实时更新。

**去留白**：删 `PLAYHEAD_EDGE_PADDING_PX` 常量 + JSDoc；`applyPointer` 夹取由 `[12, W-12]` 改为 `[0, W]`。播放头可达时间 0 与歌曲末尾。**不做线宽补偿**（贴边 1px 线可能被视口边半裁，用户接受）。

**统一拖拽**：
- 删 TimeRuler 擦洗（`seekAt` + 三 pointer handler + `scrubbingRef` + canvas `onPointer*`）。
- canvas 退化为纯渲染；保留 `cursor-col-resize` class（harness `rulerRect()` 定位所需），加注释说明。
- PlayheadLayer 结构：外层新增「不动外壳」（`absolute inset-0 pointer-events-none`），内含
  - 被 transform 的根（`headRef`）：1px 线 + 顶部块 + **9px 竖条**（`top` 由 `0` → `RULER_HEIGHT_PX`，覆盖分析轨 + 波形带）
  - **全宽尺子带**（新增，不随播放头移动）：`left-0 top-0 w-full`，`height: RULER_HEIGHT_PX`，`pointer-events-auto`，绑定与竖条相同四个 handler
- `hostRect` 仍读 `headRef.current.parentElement`（现为外壳，与容器同矩形，x 换算无漂移）。

**实时读数**：
- `handleFrame` 内，`pointerIdRef.current !== null`（本层拖动中）时，每帧 `useEditorStore.getState().setPlayhead(resolvePlayheadMs(adapters))`。
- 仅写 store，不 seek 音频 —— `audio.seek` 留在松手时一次，避免播放态每帧重建 `AudioBufferSourceNode`（爆音）。
- 频率 ≤ 刷新率，不另加节流。
- `useAudioPlayback` 的 `isScrubbing()` 守卫保留不动。

## 四、还没干

### 已知取舍
- 拖动期间 store 每帧写 → 拖动中 PlaybackBar 约按刷新率重渲染（仅拖动期间）。
- `pauseAudioOnSeek=false`（音频在播）时，拖动期间音频不再连续跟随，松手一次性 seek。
- 贴边 1px 线可能被视口边半裁（接受，不做补偿）。
- canvas `cursor-col-resize` class 保留是 harness 定位所需（非交互语义）。
- 竖条 / 尺子带 / 箭头三者读数实现来源不同，但行为一致。

### 未验证

- 音频 S1/S3/S5 边缘（播放中 context 死亡 / peakState=idle 无占位 / worker 空 levels）。
