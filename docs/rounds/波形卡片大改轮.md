## 二、上半 · 内核宽度冻结

- 现象：浏览器缩放下 canvas 右侧纯黑；容器 412 / 638 / 900 三档实测 canvas.style.width 恒 766px，不随容器变；容器 ≤ 766 时黑条消失。
- 实测数据：canvas width=958 / style.width=766 / 容器=900 / dpr=1.25；958/766=241/193=1.25，位图与 CSS 自洽 → 问题不在 dpr。
- 根因：内核 ResizeObserver 建在 ref 回调（setRootRef → attachViewport）内，拆除在 kernel.destroy()（effect cleanup）。React 18 StrictMode 双调用 effect：挂载后立即跑一次 destroy()，拆掉 RO 并置 viewportEl=null；ref 回调不重挂 → RO 永久死亡。destroy() 不清零 viewportWidthPx → 冻结在最后一次测到的 766。对照：波形高度、滚动条 track 的 RO 都建在 useEffect 内，故正常。
- 修法（1 文件 TimelineStrip.tsx）：setRootRef 只保留 rootRef.current = element（去掉 attachViewport），deps 改 []；新增 useLayoutEffect(() => { attachViewport(rootRef.current); return () => attachViewport(null) }, [attachViewport])；补 import useLayoutEffect。
- 为什么成立：绑定归 effect 生命周期，StrictMode 的 cleanup→setup 确定性重建 RO，不依赖 ref 是否重挂。

## 三、下半 · 时间轴末端语义

- 现象：未加载音频时时间轴标到 00:35（空时间轴）；加载音频后右侧大块空地；播放头卡在末端、与底部读数分裂。
- 根因：
  1) durationMs 一个值担四种角色（内容下限 / fit 分母 / 量程上限 / 播放头上限）；MIN_DURATION_MS=30_000 是「35s」来源（demo 内容 ≈25920 < 30000）。
  2) resolvePlayheadMs 有音频时无条件取端口时间，而端口 seek 夹回音频时长 → 竖线回弹，store 保留尾巴值 → 线与读数分裂。
- 用户拍板：时间轴范围可大于内容（保留 5s 尾巴，供末尾歌词块余量）；播放头可停在时间轴上任意位置（含尾巴区）；尾巴区按「播放」→ 先回内容末尾再播。
- 修法（3 文件）：
  - TimelineStrip.tsx：MIN_DURATION_MS 30_000 → 5_000（JSDoc 同步）。
  - editorCommands.ts：resolvePlayheadMs 门控加 && playback.isPlaying。
  - useAudioPlayback.ts：onStateChange 非 playing 且有音频时 setPlayhead(getCurrentTimeMs())，消除纯暂停 ≤100ms 滞后。
  - PlaybackBar.tsx：经核实不改（滑块 = 音频进度条语义；底部读数未夹取、本就正确）。

## 六、已知取舍

- MIN 改小后，极短 / 空内容时间轴变短，刻度可能更密。
- 播放走端口（精确）/ 暂停走 store（可停在尾巴区）。
- stampActiveLine 在「暂停 + 有音频」时走 store，打轴精度可能差 ≤100ms。
- 尾巴区按「播放」= 先回内容末尾再播，播放头位置被重置到音频末尾。
- 跟随（TimelineStrip L137）、滚轮收拢跟随（L125、Scrollbar L162-164）、LyricTrack 高亮（L215/L419/L563）仍读端口时间——播放头在尾巴区时拿到音频末尾值，本轮不动，列为已知边界。
- PlaybackBar 不改的理由：滑块是「音频进度条」，max = 音频时长是正确语义；播放头进尾巴区时滑块停末端表达「音频已到头」，不构成分裂。

## 八、否决的备选方案

- 不动 MIN、改在 durationMs 表达式里给 demo 特判 → 污染唯一语义，否决。
- 去掉下限设 0 → 极短/空内容时间轴塌成一条线，否决。
- 暂停也读端口 → 播放头永远进不了尾巴区，正是要解的根因，否决。
- 放开端口 seek 的夹取 → 越界（禁改 adapters），且「播放」语义失真，否决。
- PlaybackBar 自行重算时间轴时长 → 违反「不自算时长、不新增 store 字段」，且滑块语义不同，否决。
- 拆 contentMs / timelineMs 两值（6 文件 / 2 轮）→ 已评估、未采纳：用户要「时间轴可大于内容」，一个量程值 + 播放头门控已满足。
