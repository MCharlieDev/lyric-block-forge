## 二、功能详述

### 2.1 音量滚轮（`PlaybackBar.tsx`）

**做了什么**：鼠标悬停在音量控件（`label` + 滑块）上时，滚轮调音量。

**怎么做**：

- 挂点：音量 `<label data-volume-control>` 上挂**原生** `addEventListener('wheel', handler, { passive: false })`。
  - **为什么必须原生**：React 17+ 把 `onWheel` 注册为 passive，`preventDefault()` 无效。
- 累加器（`useRef({ acc, dir })` 跨事件保留）：
  - `normalized = deltaMode === 1 ? deltaY * WHEEL_LINE_HEIGHT_PX : deltaY`
  - **反向清零**：`sign !== dir` → `acc = 0; dir = sign`
  - `acc += normalized`
  - `steps = Math.trunc(acc / WHEEL_STEP_UNIT_PX)`；`steps === 0` → return
  - `acc -= steps * WHEEL_STEP_UNIT_PX`（保留余数）
  - `setVolume(clamp(volume - steps * WHEEL_STEP))`
- handler 内用 `useEditorStore.getState().playback.volume` 读最新值（避免闭包陈旧），effect 只挂一次。
- 防穿透：`preventDefault()` + `stopPropagation()`（事实层面无共同祖先挂 wheel，属保险）。
- 常量（`PlaybackBar.tsx` 本地）：`WHEEL_STEP=0.05`、`WHEEL_STEP_UNIT_PX=100`、`WHEEL_LINE_HEIGHT_PX=16`。

**不改变**：range 的点击 / 拖动交互。

### 2.2 网格吸附（`constants.ts` + `TimeRuler.tsx` + `LyricTrack.tsx`）

**做了什么**：吸附候选新增「刻度尺网格」，且网格候选**只算视窗内**。

**怎么做**：

- `constants.ts`：**新增并导出** **`LABEL_MIN_GAP_PX = 96`**；`TimeRuler.tsx` 删本地同名 const、改为 import（复用同一档刻度）。
- `constants.ts`：**新增** **`GRID_SNAP_BUFFER_PX = 8`**（= `SNAP_PX`）。
- `collectTargetsMs` 改造为「组装单一候选数组」：
  - `snapEnabled === false` → `return []`
  - `snapToPlayhead` → push `getPlayheadMs()`
  - `snapToLineTimes` → push 其他行时间戳（排除参与集自身）
  - `snapToGrid` → push `collectGridTimesMs()`
- `collectGridTimesMs`：
  - `view = kernel.getFrame().view`；`width = kernel.getViewportSize().widthPx`
  - `stepMs = adaptiveGridMs(view.pixelsPerMs, LABEL_MIN_GAP_PX)`
  - `bufferMs = GRID_SNAP_BUFFER_PX / view.pixelsPerMs`
  - `firstMs = Math.ceil((view.startMs - bufferMs) / stepMs) * stepMs`
  - `toMs = view.startMs + width / view.pixelsPerMs + bufferMs`
  - 从 `firstMs` 到 `toMs` 步进 `stepMs` 收集
- 吸附阈值仍 `SNAP_PX`；候选**等权**（`snapOffsetPx` 取全局最近）。

### 2.3 吸附对齐辅助线（`LyricTrack.tsx`）

**做了什么**：吸附命中时在吸到的时间点画一条竖线；拖动中显示、松手消失；覆盖所有吸附目标；命令式绘制（零 React state）。

**怎么做**：

- `snapOffsetPx` 返回值由 `number` 改为 `{ offsetPx: number; snappedMs: number | null }`（命中→`bestMs`，未命中→`null`）。两处调用点（拖动中 / 松手）同步适配。
- 在 `planeRef` 平面层内加**单例元素**：`ref=guideRef`、`data-snap-guide`、`pointer-events-none`、`absolute left-0 top-0 h-full w-px bg-accent`，`z-index` 高于拖动块。
- 位置：轨道坐标 `x = snappedMs * snapshot.pixelsPerMs` → `el.style.transform = translate3d(x,0,0)`；同时命令式写 `el.dataset.snapMs`。
- 显隐（只写 inline style，**禁用 Tailwind** **`hidden`**）：`pointerdown` 重置 `display:none`；`pointermove` 越阈值后命中→`block`、未命中→`none`；`pointerup / pointercancel / blocked / 未拖动点击`→`none`；统一收口到 `clearSessionStyles` 内 `hideGuide()`。
- stamp 路径（单块未打轴）共用同一 `moveNodes(snapOffsetPx(...))` 分支，**天然显示**，无需额外分支。

### 2.4 设置面板改造（`settingsStore.ts` + `SettingsMenu.tsx`）

**做了什么**：固定高度 + 内容区滚动 + 顶部搜索框；新增「时间轴 · 吸附」段。

**怎么做**：

- `settingsStore.ts` 新增四项（`AppSettings` + `DEFAULT_SETTINGS` + `normalizeSettings` 白名单各补一条，用 `typeof === 'boolean'` 校验）：
  - `snapEnabled: boolean`（默认 `true`，总开关）
  - `snapToPlayhead: boolean`（默认 `true`）
  - `snapToLineTimes: boolean`（默认 `true`）
  - `snapToGrid: boolean`（默认 `false`）
- `SettingsMenu` **重构为数据驱动**（`SECTIONS` 元数据数组 + 渲染器），每项 `{ id, label, keywords?, control }`；加 `data-settings-section` / `data-settings-item`。
- 面板结构（`SETTINGS_PANEL_HEIGHT_PX = 420`，`maxHeight: 70vh`）：
  - 外层 `flex flex-col`，固定高；
  - 顶部 `data-settings-search`（固定不滚）；
  - 内容区 `data-settings-scroll`（`overflow-y-auto`，唯一滚动）；
  - 底部 `data-settings-footer`（固定不滚，含「恢复默认」按钮，从原「导入预设」段移来）。
- 新增段「时间轴 · 吸附」置于「时间轴 · 跟随」之后：总开关 + 三个子项；**总开关关 → 三个子项** **`disabled`** **+ 置灰**。
- 搜索过滤（`useState<string>`，不持久化）：`q=''` → 全量；`section.title` 匹配 → 该段全部项；否则 `items.filter(label + keywords includes q)`；空段跳过；全空 → 显示「无匹配设置」（`data-settings-empty`）。

## 三、收尾修正

### 3.1 音量滚轮方向（纠规格错误）

- **B 段正文一直是** **`volume - steps * WHEEL_STEP`（正确）；是我给出的验收枚举写错了方向。**
- 已改：实现为 `volume - steps * WHEEL_STEP`（**上滚** **`deltaY<0`** **→ 音量增大**）。
- 验收枚举同步改：AY.a `0.5 → 4×(-50) → 0.60`（原 0.40）；AY.c → `0.55 / 0.55 / 0.50`；AY.d 上界改用 `(-100)`、下界改用 `(+100)`。

### 3.2 `maxPixelsPerMs` 核实（由推断变为事实）

- **不存在** `maxPixelsPerMs`（小写）标识符；等价钳制常量是 **`MAX_PIXELS_PER_MS = 0.5`**，定义于 [constants.ts:14](file:///d:/CodeProjects/LRC-Editor/src/ui/timeline/constants.ts#L14)（注释「最大缩放：1 秒 = 500px」，**非本轮新增**）。
- 钳制函数 `clampPixelsPerMs` @ [timeMap.ts:63-66](file:///d:/CodeProjects/LRC-Editor/src/ui/timeline/timeMap.ts#L63-L66)：`Math.min(MAX_PIXELS_PER_MS, Math.max(lower, pixelsPerMs))`。
- 应用点 `zoomAt` @ [useTimelineViewport.ts:369-374](file:///d:/CodeProjects/LRC-Editor/src/ui/timeline/useTimelineViewport.ts#L369-L374)（第 372 行）→ 是**绝对上限**，非单次比例上限。
- `applyView` @ [useTimelineViewport.ts:253-256](file:///d:/CodeProjects/LRC-Editor/src/ui/timeline/useTimelineViewport.ts#L253-L256) 只保下界 `Math.max(nextPixelsPerMs, 1e-9)`、**不上钳上限** → 上限唯一来源即 `zoomAt`。
- **结论**：`setView(startMs, visibleMs)` 存在隐性天花板；最小 `visibleMs = W / MAX_PIXELS_PER_MS = 2W`，实测 `W=922` → **约 1844ms**。

## 七、已知取舍 / 未验证
