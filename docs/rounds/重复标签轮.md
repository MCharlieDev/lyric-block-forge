# 重复标签轮 · 交接文档

> 状态：✅ 已闭合。core npx vitest run 25/25；npm run typecheck 退出码 0。
> 依赖：元数据布局轮（metadataLayout 由本轮取代）。
> 下游：空行轮（V3）。

## 一、本轮做了什么

修 V1（重复标准标签）+ V2（重复自定义标签）。把
format.metadataLayout?: string[][] 升级为
format.metadataTags?: Array<Array<{name;value}>>（同槽位、元素变富、不并存）。

## 二、关键设计

- pristine 判据：每个记录名 deriveValue(name) === 展平阅读序末值，
  且无「有值未被记录覆盖」的名 → 逐字写回（含重复、含分行）；
  否则整体退回现状（单行标准序 + 未知名）。
- 自定义值承载：meta.custom: Record<string,string>（末值）；
  serialize 侧 deriveValue 复用该渠道，无需新增字段。
- parse：删 seenNames / layoutHasDuplicate 与判重逻辑；meta 末值覆盖不变。
- serialize：新增 STANDARD_META_NAMES / deriveValue / metadataIsPristine；
  删除上轮「有布局 + leftover」分支。

## 四、已知取舍

- pristine + 全未知名 + preserveUnknownTags=false → 空元数据行，不补特殊分支。
- meta.custom 维持覆盖语义；重复自定义名多值只在 metadataTags。
- 非 pristine 一律整体退回，不做部分保真。
- V3/V4 保持 test.fails 不动。
