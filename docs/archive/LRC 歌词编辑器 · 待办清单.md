## 二、后续轮次（按依赖顺序）

### 1. 选择层去类型化

- **目的**：支持跨类型多选（比如一次删掉 2 个已打轴 + 1 个未打轴）
- **做法**：类型限制从选择层移到操作层
  - 选择层：不设限制，任意选
  - 操作层：类型无关的操作（删除/复制/剪切）吃全集；类型相关的操作（偏移/微调）自动过滤到已打轴子集
- **待定**：混合集合拖动 UX（推荐 not-allowed，A/B/C 三选一）
- **前置**：第二批完成后立刻做

### 2. 波形跟随平滑动画

- **现象**：播放头到右侧时视口突然翻页，用户看不出跑到哪了
- **方案**：分页式 + 短过渡（150\~200ms）
- **要点**：
  - 触发用 10Hz 的 onTick（够了），动画用 rAF（每帧）
  - 落点固定（翻页后停在视口 30% 处），不是固定距离
  - 可中断（用户手动平移 / 缩放 / 拖块时立刻取消）
  - 常量：`FOLLOW_TRIGGER_RATIO=0.85`、`FOLLOW_LANDING_RATIO=0.30`、`FOLLOW_ANIM_MS=160`、`FOLLOW_MIN_INTERVAL_MS=1500`
- **规模**：小（改 `followPlayhead` 一个函数）

### 3. 音量滚轮

- **做法**：鼠标悬停在音量滑块上时，滚轮调音量
- **要点**：步长 5%、clamp \[0,1]、必须 preventDefault
- **规模**：极小（10 分钟）

### 4. 吸附扩展

- **现状**：只吸附播放头 + 其他行时间戳
- **待补**：网格线 / 节拍点 / 人声起点
- **规模**：小

### 5. 重大改变弹窗

- **触发**：`isMajor=true` 的操作（整体偏移、多选偏移、批量撤销）
- **内容**：影响哪些行、变化量、撤销后能否恢复
- **前置**：多选拖动上线后才有真实触发场景
- **规模**：中

### 6. 字级拖动

- **做法**：时间轴上拖字级块边界 → 改切割点
- **交互**：双击切一刀 / 拖到尽头合并 / 拖边界改范围
- **前置**：字级只能从 enhanced LRC 来，普通 LRC 导入后字级为空
- **规模**：大

**前置**：字级拖动先做完（分析结果要落到字级才有意义）

## 八、关键决策记录（易忘）

- **锚点定类型**：集合类型由锚点决定（已打轴 / 未打轴），异类不可进集合
- **无选中是合法状态**：空格不打轴、方向键选第一可见行
- **撤销后选中不恢复**：reconcile 只清不设（零.6）
- **拖动中不写 store**：位置由日志重放结果决定
- **未打轴行不可参与 offset 拖动**：单块未打轴仍走打轴路径
- **selection-offset 目前不加弹窗**：等重大改变弹窗那轮
- **导航（方向键）和执行（空格）分开**：导航给默认起点，执行必须有目标
- **快捷键默认键位优先左手可达区**（home row 附近）
- **`set()`** **只写要改的字段，不做全量重置**（架构约定）
