三条易错：① 「讨论过没发」不等于漏，去 §5 看；② 别用评审腔，摆裁决点自己选；③ 明确 > 推测。

## 1. 工作方式

- **双闸门**：A 段只出方案/核实不写码 → AI 判 → B 段执行 → AI 判。A 没走完 B 不发。
- **交付格式**（逐字）：1.已验证 / 2.未验证 / 3.已知取舍 / 4.否决的备选方案
- **拆轮线**：改 >4 文件 / 新增 >2 组测试 / 1 次压缩 → 拆；**重构+新增并存 → 必拆**。

## 2. 校准

明确 > 推测；同口径 = 一个概念全项目一个定义；别让隐式不变量裸奔；拒绝≠静默；
**离散输入（滚轮/翻页）才补平滑；连续输入（拖动/按住）不补，跟手即可**；
「改了没效果」先硬刷新（Ctrl+Shift+R）再下结论。
无损的对象是创作者意图，不是字节；缺陷/机器产物归一化掉，不为其保存特性。

- 红字原则适用设定（真红字 vs 测试缺陷的分界）见《LRC 编辑器项目 · 协作规程》§六。

## 3. 项目定位

LRC 歌词编辑器，辅助创作者（非傻瓜编辑器）；重大改变要弹窗；离线无服务端。
分层 core / adapters / ui / shells；时间统一毫秒整数；音频时钟是播放唯一基准。

## 6. 技术事实（速查）

**播放头**

- 收口两函数（editorCommands.ts）：resolvePlayheadMs（拖动中→会话值；有音频→端口；否则→store）/ seekPlayhead（setPlayhead + 有音频才 seek）。
- resolvePlayheadMs 门控：scrubMs 优先 → 「有音频 且 isPlaying」走端口 → 否则走 store。即「播放走端口（精确）、暂停走 store（可停在尾巴区）」。
- MIN\_DURATION\_MS = 5\_000（原 30\_000）。无音频启动实测 durationMs = 30920（demo 内容 25920 + 尾 5000）——不是 10000，也不是旧的 35000；10000 只在真正空文档（0 行 0 音频）成立。
- 拖动会话 = 模块级单例 scrubMs（非 store、非 React）。
- 留白已删；播放头屏幕位夹 \[0, W]（可达时间 0 与末尾）。
- 统一拖拽：尺子任意处 = 抓播放头；TimeRuler 已无手势（canvas 退化纯渲染，保留 cursor-col-resize class 仅供 harness 定位）。
- PlayheadLayer 结构：不动外壳 + 全宽尺子带（top 0..RULER\_HEIGHT\_PX）+ 9px 竖条（RULER\_HEIGHT\_PX..LYRIC\_TRACK\_HEIGHT\_PX）。
- 边缘自动滚 = 复用内核 startAutoPan/stopAutoPan（Scrollbar 同款）；触发带 EDGE\_ZONE\_PX=48，速度 ∝ 越界深度，上限 EDGE\_PAN\_MAX\_SPEED\_PX\_PER\_S=1500。
- 拖动中每帧写 store（handleFrame，门控 pointerIdRef，≤刷新率）；audio.seek 仅松手一次。
- useAudioPlayback 的 isScrubbing() 守卫保留。

**当前行（光标 / 选区）**

- **两个概念**：`activeLineId` = 光标（唯一真源）；`lineIds` = 选区（多选范围）；`anchorLineId` = 范围选锚点。三者同属 `selection`。
- **DOM 焦点跟随光标**：`LyricBlockPanel` 内一个 effect，`activeLineId` 变则把焦点移到对应行（`preventScroll: true`）；目标已是 `activeElement` 则早退（防自激）。
- **`setCursorOnly(lineId)`**（editorStore）：Tab 导航专用——`lineIds` 清空、`activeLineId` / `anchorLineId` 设为该行。与 `selectLine` 的区别：后者把选区替换为「新行单选」。
- **行** **`onFocus`** **双守卫**：① 光标已在本行则早退（挡焦点跟随 effect 的程序化聚焦）；② 仅 `:focus-visible` 为真（键盘来源）才走 `setCursorOnly`，鼠标点击聚焦交给 `onClick`（实测：鼠标 → `false`，Tab → `true`）。
- **行热区去掉默认 outline**，焦点视觉由 `isActive` / `inSelection` 承担，不再有第二个描边。
- **语义矩阵**：Tab → 挪光标 + 清空选中；↑↓ → 挪光标 + 单选重置；`Ctrl+↑/↓` → 挪光标 + 保选中；空格打轴 → 永远打光标行。完整键位见下「键盘多选（第二轮）」。

**harness**

- **harness 位置**：仓库内 `harness/`（`run.mjs` + 4 探针已入库，commit `e5e0232`；`harness/launch.mjs` 已提交，commit `72ce159`）。
- **启动方式**：`npm run harness`（跑完自动回收 vite / chrome）；`npm run harness -- AX`（筛选组透传）；`npm run harness:keep`（保留进程，便于手工连 CDP）。
- **端口参数化**：`LRC_DEV_PORT`（默认 5177）、`LRC_CDP_PORT`（默认 9333）；隔离验收可用 5277 / 9433，不干扰常驻服务。
- **launch.mjs 冷启动流程**：起 vite（`--strictPort`）→ 等 dev 探针 → 起 headless Chrome（启动参数末尾直接带 APP）→ 等 CDP 探针 → `prewarm()` 只等待（`readyState==='complete'` + resource 数量连续 1.5s 不增长 + 出现 `/stores/editorStore.ts`，上限 30s）→ spawn `node harness/run.mjs` 并 tee 到 `harness/.tmp/logs/`。
- **失败取证**：run.mjs 退出码非 0 时，回收进程前先连 CDP 打印 href / readyState / resource 数 / 前 10 个 resource / `window.__bootError`（可选 `Page.getNavigationHistory`）。
- **不要踩**：`vite.config.ts` 的 `watch.ignored` 必须写 `'**/harness/.tmp/**'`（缺 `**/` 前缀匹配不到绝对路径，Chrome profile 被 watcher 盯上会 EBUSY / 整页重载）；headless 下「about:blank 启动 + CDP 二次导航」拿不到资源，必须启动即带 APP。

**键盘多选（第二轮）**

- **键盘键位矩阵**：

| 键                  | `activeLineId` | `lineIds`       | `anchorLineId` |
| ------------------ | -------------- | --------------- | -------------- |
| ↑ / ↓              | 挪到相邻可见行        | 重置为「新行」单选       | 跟到新行           |
| `Ctrl/Cmd + ↑ / ↓` | 挪到相邻可见行        | 不动              | 跟到新行           |
| `Ctrl/Cmd + Enter` | 不动             | 光标行加入 / 移出（可空）  | 跟到光标行          |
| `Esc`              | 不动             | 清空              | 跟到光标行          |
| `Shift + ↑ / ↓`    | 挪到相邻可见行        | 从 anchor 范围选到新行 | 不动             |

- **新 action（editorStore）**：`setActiveLine(lineId)` = 只挪光标、保 `lineIds`、重设锚点（与 `setCursorOnly` 唯一区别 = 后者清空 `lineIds`）；`toggleActiveLineSelection()` = 光标行开关（在选区则移出、否则加入，可减到空；光标不动、锚点跟光标行；无光标 no-op）。
- **新命令（editorCommands）**：`moveSelectionRange(direction)` = `Shift+↑/↓`，复用 `selectLineRange`（无光标退化 `selectLine(visible[0])`）；`clearSelectionKeepCursor()` = `Esc`，读 `activeLineId` 非空则调 `setCursorOnly`；`toggleCursorSelection()` = 薄封装调 `toggleActiveLineSelection()`。
- `moveSelection(direction, { keepSelection })`：`keepSelection: true` → `setActiveLine`（保选区）；省略 → `selectLine`（现状）。
- `nudgeSelection` 阈值 2→1：`lineIds` ≥ 1 走集合口径（旧状态 `lineIds` 单行时 `activeLineId` 必等于该行 → 等价；新状态 `{lineIds:[A], active:B}` 由「动 B」改「动 A」）。
- hotkeys：`DEFAULT_HOTKEYS` 新增 `toggleCursorSelection: 'Enter'` / `clearSelection: 'Escape'`；`prevLine` / `nextLine` 加 Ctrl（keep）/ Shift（range）分流；行热区 `onKeyDown` 放行带修饰键的 Enter（`Ctrl/Shift/Alt+Enter` 交给 window，纯 Enter 仍行内 `selectLine`）。

**滚轮/视口**

- WHEEL\_LERP=0.6（\~100ms）；帧率无关 alpha；**dt 必须 Math.max(0, dt)**（否则反向抽搐）。
- 滚轮屏蔽跟随用内核 wheelSuspendsFollow。
- autoPan 首帧 dt 可能 <0；其自停需 dt>0 守卫（本轮修）。

**歌词块排版**

- 宽度 = `max(minWidth, min(contentWidth, timeGap - BLOCK_GAP_PX))`；无下一行时 `max(contentWidth, minWidth)`。
- `minWidth = max(信息行宽 + 14, 40)`；`contentWidth = max(正文, 信息行, 译文) + 14`。
- 放大态（`ppms >= 0.30` 且该行有 chips）为 word 模式：`contentWidth = wordRowWidth + 12 + 4 + 14`、`minWidth = max(40, 52)`；`timeGap` 压缩后 `cap < 52` 且内容超 `cap` 时降级为 14px 菱形块（整块即把手）。
- `wordRowWidthPx` 仅 word 模式参与内容宽（line 模式仍为 `null`）；chip 宽 = `max(文本宽 + 8, 22)`、chip 间距 2px。
- 阶梯内核（轮 1 建、轮 2 已接线）：`LineWidths.wordChipContentWidthsPx` = 纯文本宽（不含 8、不含 badge、不受 22 下限）；`stackWordChipWidths(full, content, times)` 把「相邻且时间严格相等」的组改成阶梯宽（`W0 = 4 + c0`、`Wi = W(i-1) + 2 + ci`、末卡再 +4，组总宽 = `8 + Σc + 2(N-1)`），左缘仍由 `layoutWordChips` 决定。轮 2 起 `deriveDisplayChips` 逐字成卡（不再合并），LyricTrack 在 `layoutWordChips` 前调用 `stackWordChipWidths`，LyricBlock 用 `paddingLeft = 前一张 widthPx + 2` 推内容、`renderOrder` 组内倒序（首张最后绘制 = 最上层，不用 z-index）、仅组首渲染时间戳并 `overflow-visible` 溢出。
- 行分配：第一遍占位宽取内容上界 → 只缩不涨、行号不被推翻；代价是「过度分行」（fit 全景下可能从单行变两行交替）。
- 回退：贪心选 `lastEndPx` 更小的行；等宽场景等价于 0/1/0/1 交替。
- 渲染顺序：`visibleRows` 按 `startPx` 升序（同起点按文档序）；`overlapsPrev` 由第二遍同行最终几何判定。
- 末块以 `durationMs` 作虚拟右边界，且只在 `startMs < durationMs` 时生效。

**音频**

- AudioContext closed/interrupted 时重建；load 原子化（不变量：store 有 asset ⇒ 端口有 buffer）。

## 9. 关键决策（易忘）

- 撤销后选中不恢复；拖动中每帧写 store（读数实时）；audio.seek 仅松手（避免播放态每帧重建 source 节点）；多选删除落点=直接无选中。
- 精度统一只在导出层，默认三位。
- 播放头拖动：按住即接管；松手用 pointerup 坐标重算；顺序 seekPlayhead → endScrub。
- 音频「拖动播放头是否暂停」：维持现状，不再折腾（原待办的开关状态 / B或C 已取消）。
- viewportWidthPx 单一真源：canvas 宽度只认内核快照；测量归 effect（useLayoutEffect 里 attachViewport），不放 ref 回调——否则 React 18 StrictMode 双调用 effect 会 destroy 掉 RO 而 ref 不重挂，宽度永久冻结。
- durationMs 仍一个值担多角色（内容下限 / fit 分母 / 量程上限 / 播放头上限）；本轮只去掉 30s 下限，四角色合一未拆（contentMs/timelineMs 拆分方案已评估、未采纳）。
- 尾部保留 5s（DURATION\_TAIL\_MS），用途 = 末尾歌词块显示余量；时间轴范围允许大于内容。
- 光标（`activeLineId`）与选区（`lineIds`）**分离**；焦点跟随光标，光标是「当前行」的唯一真源。
- 键盘键位矩阵（第二轮闭合）：↑↓ = 挪光标 + 单选重置；`Ctrl+↑/↓` = 挪光标 + 保选区（anchor 跟新行）；`Ctrl+Enter` = 光标行加入/移出选区（可减到空、光标不动）；`Esc` = 清空选区（光标不动）；`Shift+↑/↓` = 从 anchor 范围选到新行（anchor 不动）；Tab = 挪光标 + 清空选中。
- 唯一不变量是**单向**的：`lineIds 非空 ⇒ activeLineId 非空`；反向不成立（Tab 后可出现 `lineIds = []` 且 `activeLineId ≠ null`）。
- 零尾巴断言（AO / AQ.B×2）改「落定后取样（250ms）+ 最终收敛硬断言」；容差维持 ±3。
- harness 已迁入仓库 `harness/`（B 段-1 入库、B 段-2 加 launch 壳）；冷启动靠「Chrome 启动即带 APP + prewarm 等整页静默」，不再依赖人工先开服务。
