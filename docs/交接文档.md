## 0. 交接必读

**你的位置**：你是决策者，不是执行者。Trae 写代码，你判它的结果，用户提修改并确认。

**三条最容易犯的错**：

1. **别把"讨论过但还没发"当成漏了。** 用户习惯把讨论结果攒着、几轮后才发。交付里没有 ≠ 被忘了。去 §5 在途清单看。
2. **别用外部评审腔。** 不说"问题一严重、问题二中等"。你的位置是**拥有这份工作的人**——摆出裁决点、自己选一条、往下走。
3. **别用推断省显式判断。** 用户要"明确 > 推测"。哪怕推断今天成立，也要显式写条件。

## 1. 工作方式（硬规则）

### 1.1 双闸门

| 段           | 内容                      | 谁做                                              |
| :---------- | :---------------------- | :---------------------------------------------- |
| **A 段（方案）** | 任务书 + 核实请求，**只出方案不写代码** | 用户发 Trae → Trae 出方案 → 用户发 AI → **AI 判 + 给修改指令** |
| **B 段（执行）** | 「方案已确认，按此执行」+ 修改指令      | 用户发 Trae → Trae 改代码 + 四段交付 → 用户发 AI → **AI 判**  |

**A 段没走完，B 段不发出。**

### 1.2 交付格式（逐字，不得改写、不得省略）

```
1. 已验证：
2. 未验证：
3. 已知取舍：
4. 否决的备选方案：
```

### 1.3 任务粒度（新规则）

**任一条超标就拆轮**：

- 改超过 **4 个文件**
- 新增超过 **2 组测试**
- 出现 **1 次上下文压缩**

**更本质的一条**：**「重构」与「新增」同时存在 → 必须拆。** 重构的风险是"弄坏旧的"，新增的风险是"新的不对"，混在一起判断时分不清谁的锅。

（教训来源：小项整合轮塞了 4 功能 + 1 次 `SettingsMenu` 数据驱动重构，触发多次压缩。）

### 1.4 其他

- **「题外话」= 脱离项目**。AI 只给意见，不产出物料。说一句带项目内容的话即切回。
- **检查点提醒**：每个大部分闭合、AI 判过之后，提醒用户更新本文档。
- **弹窗 / toast 一律自研**，禁 `window.confirm` / `alert` / `<dialog>`。
- **讨论 ≠ 发送。**
- **核实报告必贴全**（判断依据），**执行报告可截**（省钱）。
- **界面限制**：Trae 思考中**无法接收消息**；只能在它停下（交付或提问）时发送。

## 2. 校准（判断原则）

- **明确 > 推测。** 宁可多写显式条件。
- **同口径 = 一个概念全项目只有一个定义。** 不是"两处写得像"，是"三处调同一个函数"。
- **保底留成"一个函数"，不留成"两处各写一遍"。**
- **别让隐式不变量裸奔，给它一道明写的锁。**
- **拒绝 ≠ 静默**：拒绝 = 有落差、被挡住 → 需提示；静默 = 本身没意义 → 不解释。
- **流利会盖住空缺。** 语气确定 ≠ 真有知识。所以有核实步。

## 7. 技术事实速查（已核实，别凭记忆）

**回放 / 时间戳**

- `ReplayState.lineTimestamps: Record<string, number[]>`（只有数字，无精度）
- `OperationDelta` mode：`offset / absolute / none / line-text / remove-line / clear-timestamps`
- 「是否已打轴」= `getReplayedLineTimes(replay, id).length > 0`
- 「可平移」= `lineIsMovable(replay, id)` = 未删 && 已打轴（三处共用）
- 「无选中」= `{ lineIds: [], activeLineId: null, anchorLineId: null }`

**清空语义（两种，含义相反）**

- 改文本 → 连切分一起抹（`editLineText`）
- 清空时间戳 → 只清时间、保留切分（`clear-timestamps` **不进** `clearedWordLines`）
- 文本变更优先

**导出**

- 唯一组装函数 `buildExportText(document, replay, precisionMs)`，App 与 harness 共用
- 命中 `clearedLineLines` → 输出纯文本（防复活）
- 精度统一只在导出层，默认三位
- `format.metadataTags?: Array<Array<{name;value}>>` 取代旧 `metadataLayout`
  （同槽位、元素变富、不并存）；缺省 `undefined` = 退回单行标准序
- **pristine 判据**：每个记录名 `deriveValue(name) === 展平阅读序末值`，且无
  「有值未被记录覆盖」的名；满足则逐字写回（含重复/分行），否则整体退回现状
- **自定义标签值承载**：`meta.custom: Record<string,string>`（末值）；
  重复自定义名的多值只在 `metadataTags` 里

**跟随**

- `FOLLOW_TRIGGER_RATIO=0.8`、`FOLLOW_TARGET_RATIO=0.2`、`FOLLOW_ANIMATION_MS=160`
- 两状态：`followSuspended`（拖块，无条件挂起）/ `followPaused`（B 模式）
- `followPaused` 为真 → `followPlayhead` 直接 return（含"屏外直接跳"）
- 三项设置：`followResumeMode(snap/pause)` / `pauseAudioOnPan` / `pauseAudioOnSeek`（后两项默认 true）
- `setFollowPaused(true)` 只在**两个用户手势入口**（滚轮平移 / 滚动条拖拽），**不在** `panByPixels`/`applyView`

**吸附（本轮新增）**

- 网格候选**只算视窗内**（含 `GRID_SNAP_BUFFER_PX = 8` 缓冲）
- 网格档位复用 `adaptiveGridMs(ppms, LABEL_MIN_GAP_PX=96)`，与 TimeRuler 同口径
- 四项设置：`snapEnabled`(T) / `snapToPlayhead`(T) / `snapToLineTimes`(T) / `snapToGrid`(**F**)
- 对齐辅助线在 `LyricTrack` 的 plane 层内，`data-snap-guide`，命令式 inline style

**音量滚轮（本轮新增）**

- **上滚（`deltaY<0`）→ 音量增大**；`setVolume(volume - steps * WHEEL_STEP)`
- 累加器：同向累加、**反向清零**；`WHEEL_STEP=0.05`、`WHEEL_STEP_UNIT_PX=100`、`WHEEL_LINE_HEIGHT_PX=16`
- 原生 `addEventListener('wheel', …, { passive:false })`（React `onWheel` 是 passive，`preventDefault` 无效）

**视口 / 缩放**

- **`MAX_PIXELS_PER_MS = 0.5`**（[constants.ts:14](file:///d:/CodeProjects/LRC-Editor/src/ui/timeline/constants.ts#L14)，"1 秒 = 500px"），由 `clampPixelsPerMs`（[timeMap.ts:63-66](file:///d:/CodeProjects/LRC-Editor/src/ui/timeline/timeMap.ts#L63-L66)）在 `zoomAt` 中施加
- → `setView(startMs, visibleMs)` 有**隐性天花板**：最小 `visibleMs = 2W`（实测 W=922 → ≈1844ms）
- 纯平移不触发块布局重算（`laidOut` 只依赖 `pixelsPerMs`）；每帧只改容器 `translate3d`

## 10. 关键决策记录（易忘）

- **锚点回归本义**：只作范围选起点
- **撤销后选中不恢复**：`reconcile` 只清不设
- **拖动中不写 store**：命令式 transform，松手才写一条日志
- **混合集合（含未打轴）**：拖动拒绝（not-allowed），微调拒绝（toast）
- **多选删除**：落点 = 直接无选中；单行按钮删除 = 挑最近剩余
- **精度统一只在导出层**，默认三位
- **跟随启停绑定"音频是否播放"**；唯一例外是拖块（挂起跟随但不停音频）
- **A/B 恢复**：A = 松手自动拉回；B = 不拉回（`followPaused`），归位按钮是唯一显式恢复
- **音量滚轮方向**：上滚增大（`volume - steps*STEP`）
- **网格候选限视窗内**（缓冲 8px）
- **`set()`** **只写要改的字段**，不做全量重置
- **元数据保真用 pristine 闸**：未编辑→逐字写回；一旦编辑→整体退回现状
  （不做部分保真）
- **`metadataTags` 取代 `metadataLayout`**，不并存
